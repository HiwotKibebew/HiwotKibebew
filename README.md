## 🔬 Research Highlight

**A Lightweight Approach to Continuous Authentication through Keystroke Dynamics Using Neural Networks**

Published in the *HiLCoE Journal of Computer Science and Technology (2025)*.

### Data Preparation and Analysis
Developed Python scripts to clean, transform, and aggregate 225 space-delimited keystroke log files from 75 users into structured, model-ready datasets. Conducted statistical analysis and data visualization using Pandas, Excel, Matplotlib, and Seaborn.

### Feature Engineering
Developed compact 3D key embeddings and seven-dimensional keystroke features. Applied Principal Component Analysis (PCA) to reduce 106-dimensional key representations to three components while retaining 96.22% of the variance, and eliminated redundant timing features to improve computational efficiency.

### Model Evaluation
Compared deep learning architectures, performed grid-search hyperparameter tuning, and evaluated model variants using TensorFlow. Assessed authentication performance using Equal Error Rate (EER), False Acceptance Rate (FAR), and False Rejection Rate (FRR), achieving average EERs of 5.14% for internal test users and 6.19% for external test users.
